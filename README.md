# Construction-Sales-Analytics
Interactive construction sales analytics dashboard developed using Microsoft Excel, Power Pivot, Data Model, PivotTables and VBA.
PLATFORM AND FEATURES USED
This project was developed using Microsoft Excel as an advanced business analytics and dashboarding platform. Excel was used to transform raw business data into an interactive and user-friendly management dashboard.
Key features and tools used in the project include:
•	Excel Tables – Used to organize and structure the five datasets for easier data management and analysis.
•	Power Query – Used for data cleaning, transformation, standardization, and preparation before analysis.
•	Power Pivot – Used to create the Data Model, establish relationships between tables, and perform advanced calculations.
•	Data Model & Relationships – Connected sales, projects, clients, estimators, costs, calendar, and region data to enable integrated analysis.
•	DAX Measures – Used to calculate KPIs such as Contract Value, Total Sales, Win Rate, Gross Profit, Budget Utilization, and Target Achievement.
•	PivotTables – Used to summarize and analyze business performance across different dimensions such as time, region, client, project, and estimator.
•	PivotCharts – Used to present trends, comparisons, and performance analysis visually.
•	Slicers & Timeline – Added interactive filtering by dimensions such as Region, Year, Month, Client, and Estimator.
•	KPI Cards – Used to display important business performance indicators clearly on the dashboard.
•	What-If / Scenario Analysis – Used to evaluate the impact of changes in discount rates and project costs on Contract Value, Gross Profit, and Gross Margin.
•	Conditional Formatting – Used to highlight important values, trends, risks, and performance levels.
•	VBA Macros – Used to add dashboard functionality such as Refresh, Clear Filters, Next Page, Previous Page, and navigation between dashboard sections.
•	Interactive Dashboard Design – Shapes, buttons, charts, KPI cards, and navigation controls were combined to create a professional management dashboard.
Overall Purpose
The dashboard combines data preparation, data modelling, advanced calculations, visualization, automation, and scenario analysis in one Excel-based platform. It helps management monitor business performance, identify trends and risks, compare different business areas, and make informed decisions using data.
